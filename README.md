# Personal Expense Tracker Dashboard - Excel

## Project Overview
This project is an interactive Personal Expense Tracker Dashboard created using Microsoft Excel to monitor income, expenses, savings, and spending patterns.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Charts
- Slicers
- Conditional Formatting

## Dashboard Features
- Monthly Expense Tracking
- Category-wise Expense Analysis
- Savings Overview
- Interactive Dashboard
- Visual Expense Insights

## Key Insights
- Identified major spending categories
- Tracked monthly financial patterns
- Analyzed savings and expenses
- Improved personal budget monitoring
